# DARTS IMPACT

Interactive dart impact analysis with a heatmap board, stats summary, and editable data table.

## Features
- Heatmap with blue → green → red CAE-style color scale
- Hover/tap details per segment (counts + percentage)
- Editable table for quick data entry
- CSV import to populate the table

## Usage
1. Open `index.html` in a browser.
2. Enter values directly in the DATA table, or import a CSV file.
3. The heatmap and stats update automatically.

## CSV Format (column order)
Expected columns by position:
1. No.
2. Single Inner
3. Single Outer
4. Double
5. Triple

Special rows (first column):
- `S-BULL`
- `D-BULL`
- `OUT`
